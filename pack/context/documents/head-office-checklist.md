# Head office AP verification checklist

Used by central accounts payable verifiers before posting the invoice in SAP.

| # | Check | Applies to |
|---|---|---|
| H1 | Vendor GSTIN on the bill matches the vendor master | All |
| H2 | Bill is addressed to the correct company entity | All |
| H3 | Work order or purchase order is valid on the bill date and has open balance | All |
| H4 | Rate matches the work order or purchase order | All |
| H5 | Quantity matches the posted service entry or GRN | All |
| H6 | Attendance sheet is signed | Manpower |
| H7 | PF and ESIC challans for the previous month are attached | Manpower |
| H8 | Delivery challan is stamped | Material |
| H9 | Service report is attached | AMC, repairs, testing |
| H10 | GST type is correct for the place of supply (CGST and SGST, or IGST) | All |
| H11 | HSN or SAC code and GST rate are correct | All |
| H12 | GL code and cost centre on the service entry are correct | All |
| H13 | Invoice number has not been booked before for this vendor | All |
| H14 | TDS section and rate are correct | All |

Version 5. Owned by central accounts payable.
