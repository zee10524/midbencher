# Property bill verification checklist

Used by the property commercial executive before the bill packet goes to the property head.

| # | Check | Applies to |
|---|---|---|
| P1 | Vendor name and GSTIN on the bill match the vendor master | All |
| P2 | Bill is addressed to the correct company entity and property | All |
| P3 | Work order or purchase order number is on the bill | All |
| P4 | Rate on the bill matches the work order rate | All |
| P5 | Quantity, days or headcount match approved attendance or delivery | All |
| P6 | Attendance sheet is signed by the department head | Manpower |
| P7 | PF and ESIC challans for the previous month are attached | Manpower |
| P8 | Delivery challan carries the security gate stamp | Material |
| P9 | Service report or job card is attached | AMC, repairs, testing |
| P10 | Service entry (services) or GRN (materials) is created in SAP | All |
| P11 | Property head has signed the packet | All |
